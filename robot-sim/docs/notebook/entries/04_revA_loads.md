# 04 · Rev A load check: the problem
*2026-11-25*

| | |
| --- | --- |
| CAD mass | about 2.7 kg |
| Load case | tripod stance (three feet down), foot 85 mm out from the femur axis |
| Femur torque needed | **7.7 kg·cm** |
| MG996R (6 V) | 11 kg·cm stall, about 3.5 kg·cm continuous |
| Femur load | **70 % of stall**, far beyond continuous duty |

The gait's widest stance made it worse: feet reached up to 160–190 mm from the femur axis during sprint plus turn.

**Conclusion.** Rev A would walk at a stand, but it would cook its femur servos with any attachment on. That, plus the request for a rechargeable power system and real vendor CAD, triggered rev B.
